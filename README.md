# One Piece — 官方训练营 Skill 合集

> "人的梦想，是不会结束的！" —— 黑胡子·马歇尔·D·蒂奇

欢迎来到 **One Piece**，这里是我的个人 AI 编程 Skill 训练营，收录了我在日常开发中积累和打磨的各种 Skill。每一个 Skill 都像一块"历史正文"，记录着通往高效开发之路的关键信息。

## 这是什么？

本仓库是一个精心整理的 **AI Skill 集合**，主要服务于 Claude Code 等 AI 编程助手。每个 Skill 都经过实战验证，覆盖从代码生成、文档撰写、图像处理到工作流自动化等多个领域。

## Skill 列表

下面是仓库当前收录的 Skill，每个都说明了它"是做什么的"以及"什么时候会用到"：

| Skill | 它是做什么的 | 什么时候用 |
|-------|------------|-----------|
| 🧭 **[寻找喜欢的副业](skills/find-side-hustle)**<br/>`find-side-hustle` | 扮演一位副业导师，通过深度调研了解你的兴趣、能力和资源，结合 AI 工具与自媒体趋势，帮你找到真正喜欢又能赚钱的副业方向，并给出可落地的 **30 天行动计划**。 | 说"想搞个副业 / 下班后做点啥 / 想搞钱 / AI 能帮我做什么副业"时 |
| 📺 **[B站爆款拆解](skills/bilibili-viral-deconstructor)**<br/>`bilibili-viral-deconstructor` | 输入一条 B站视频链接/BV号，自动抓取口播字幕 + 播放/三连/粉丝数据，按 **八层拆解法**（数据爆火→选题→标题钩子→开头→结构→中间钩子→情绪→结尾转化→可复用方法论）分析它为什么火，产出一份 **Apple 风格 HTML 报告** + 一份 **详细 Markdown 文档**。 | 想做对标、复盘爆款、提炼可复用套路时 |

> 持续更新中，新 Skill 会随实战需求不断加入。

### 各 Skill 的特殊配置

- **B站爆款拆解**：抓取字幕需要你**自己 B站账号**的 `SESSDATA` Cookie。把该 skill 目录下的 `.env.example` 复制为 `.env` 并填入即可（`.env` 已被 `.gitignore`，不会被提交）。这是个人登录凭证，请勿分享或提交。没有 cookie 也能用——公开的播放/三连数据照拿，字幕可改用油猴脚本导出 SRT 喂给它。

## 使用方式

Skill 可以直接在支持 Skill 体系的 AI 编程助手中使用。将对应的 Skill 文件放置到项目的 `.skills/` 目录下，即可在对话中自动加载。
